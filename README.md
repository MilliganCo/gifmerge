# gifmerge

## О проекте

`gifmerge` — утилита для объединения нескольких GIF-файлов из папки в один итоговый GIF. Скрипт не просто склеивает анимации подряд, а умеет перемешивать порядок без соседних дублей и сохранять оригинальные задержки кадров.

## Возможности

- выбор папки с GIF через диалог;
- объединение нескольких анимаций в один файл;
- случайный порядок кадровых блоков без подряд идущих дублей;
- fallback через `ffmpeg`, если `Pillow` не справляется с чтением GIF;
- сохранение исходных задержек кадров.

## Стек и структура

- Python
- `Pillow`
- опционально `ffmpeg` / `imageio[ffmpeg]`
- основной файл: `merge_gifs.py`

## Запуск

```bash
python merge_gifs.py
```

## Статус

Готовая утилита. Это компактный практический инструмент для пакетной работы с GIF-анимациями.

## Установка и проверка

Python 3.10+ и Tkinter. Установите зависимости: `python -m pip install -r requirements.txt`.
Для больших анимаций рекомендуется FFmpeg в PATH; запасной путь через Pillow держит кадры в памяти.

Результат сохраняется как `merged.gif` в выбранной папке и перезаписывает предыдущий результат.
Этот файл исключается из входного набора при повторном запуске. Имена с расширением `.GIF` тоже поддерживаются.
Порядок блоков случайный; при равном числе повторов соседние дубли исключены.

Проверка алгоритма и отбора файлов: `python -m unittest discover -s tests -v`.
Взаимодействие с диалогом и совместимость разных GIF/версий FFmpeg проверяйте на копиях своих файлов.
